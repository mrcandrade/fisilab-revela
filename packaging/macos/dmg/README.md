# Janela do DMG (macOS)

Dois arquivos prontos, copiados para a imagem por `package.sh`:

- `background.tiff`: o fundo da janela do Finder.
- `dmg-layout.DS_Store`: tamanho da janela, tamanho dos ícones e posições.

Ambos são gerados por `suite-fisilab/scripts/gerar_mac.py`, no repositório
[mrcandrade/larfic](https://github.com/mrcandrade/larfic); não são produzidos neste repositório.

O layout espera o volume chamado **Revela** (sem versão), o aplicativo **Revela.app** e o atalho para
`/Applications` chamado **Aplicativos**.
